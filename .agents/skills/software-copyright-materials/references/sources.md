合作开发协议签署日期：《计算机软件著作权登记办法》未明文规定协议须早于开发完成日期，但审查实务中协议日期与开发完成日期相同或更晚会收到补正通知，见[知乎：合作开发协议日期与开发完成日期冲突](https://www.zhihu.com/question/551945885)、[哔哩哔哩：软著常见补正原因——时间、日期](https://www.bilibili.com/opus/863739526918438915)（2026年10月24日访问）。部分文章称须早三个月或六个月，无可靠出处，不作为规则。
