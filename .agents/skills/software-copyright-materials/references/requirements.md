# 软件著作权材料要求与操作检查

整理/核验日期：2026年10月1日。规章原文链接见sources.md。本说明服务于一般交存材料准备。

## 1. 官方规章中的基础要求

依据[国家版权局《计算机软件著作权登记办法》](https://www.ncac.gov.cn/xxfb/flfg/bmgz/202410/P020241015604759788122.pdf)，对条款归纳如下：申请时提供申请表、程序及文档鉴别材料和相关证明文件。一般交存的程序、文档分别取前后各连续30页；各自不足60页则交全部。除特定情况外，程序每页至少50行，文档每页至少30行。材料使用A4，中文填写官方表格。权属证明因实际开发/取得方式而异；名称、署名不一致或权属有争议可能导致不予登记。

这些规则来自第九至十一条、第十七条及第二十一条。第十二条另规定例外交存：前后30页中有限比例遮蔽机密；前10页加任意连续50页；或目标程序前后30页加源程序任意连续20页。本工具默认一般交存，例外交存须另按真实需要编排，不自行把规则混用。

## 2. 页数和行数怎么判断

| 问题 | 本归档采用的处理 |
|---|---|
| 是否必须60页 | 各自实际排版不足60页时全部交存；规章没有统一说明书15页/20页最低页数 |
| 源码超过60页 | 固定文件顺序形成全量页序，再选最前30页和最后30页。保存完整源码及全量统计 |
| 说明书超过60页 | 保存完整说明书，另生成前后各30页的鉴别选页稿，保留原页序说明 |
| 不足60页 | 真实内容全部收录，不补空行、不重复代码、不堆无关说明凑页数 |
| 长代码行 | 完整折行；一次原始源码行只计一次，续行不能增加源码量统计 |
| 空行和注释 | 空行不印刷；实际注释及版权声明保留。禁止为提高行数追加无意义注释 |
| 封面、目录、图文、结束页 | 分别记录、人工判断，不机械拿普通正文行数判定；规章仅写“除特定情况外”，最终适用由登记机构确认 |
| 纯正文页不足30行 | 先优化真实内容组织、表格或分页；不能用隐藏文字、无关内容或随意放图骗过检查 |
| 最后一页 | 应保留实际源文件/模块结尾，不用虚构“程序结束”文字替代缺失源码 |

“封面/目录/图文/结束页”的本地检查策略不是对所有申请的法定豁免清单，必须留存判断依据，服从最新指南与补正意见。

## 3. 沿用的版式和模板选择

说明书采用旧项目ctexart、Windows中文字库、小四、1.35倍行距；A4左右22mm、上24mm、下22mm。标题层级、自动目录、三线表、截图编号沿用原TeX。封面无显示页码，目录从第1页计，左上软件全称/版本、右上页码、左下权利人、右下材料类型，并保留细横线。

源码采用A4等宽字体和连续源码行号，左上软件名/版本、右上页码，底部署名和材料类型。具体字号、页边距和页脚属于本项目模板选择。页眉右上页码参考原模板及高校材料检查实践，不能声称这些具体尺寸、字体、页脚内容由第十条强制规定。

## 4. 必须与真实项目一致的内容

- 名称/版本：软件界面、TeX、PDF、配置和申请信息一致，含空格、版本大小写等逐一核对。
- 权利人：依实际权属填写，不能因为用户说“我的项目”就改变历史材料署名。合作/委托/职务项目要查相应事实。
- 日期：开发完成与发表日期需真实依据；材料制作、截图或归档日期不是自动可用的开发日期。
- 功能：说明书写到的按钮、导出、识别、评分、账号、云服务等，应找到真实实现及运行证据。
- 截图：从当前版本实际运行采集，保留原PNG和操作信息；演示数据标注来源。
- 源程序范围：只收真实实现；第三方库、压缩bundle、自动生成代码和依赖缓存不主张为原创。
- 源码交付：另有可编辑工程ZIP、锁定依赖、启动步骤；鉴别PDF不代替源码ZIP。

## 5. PDF和压缩包复核

检查A4、软件名/版本/署名、页码顺序、自动目录、截图可读性、表格分页、长代码、缺字、正文与页眉页脚距离、空白页及最后一页。全量页序和选页页序要记录；源码编号与统计中的每页区间逐项相等。

随后打开全部联系页及重要页大图。文字提取不能证明画面没有碰撞，机器报告通过仍需目视。打包后读取ZIP，校验CRC和每个文件SHA-256，确保包中材料与最终核验版本相同。

## 6. 申请表、证明及当前平台要求

基础材料涵盖：平台申请表、鉴别材料、自然人或单位身份证明；依实际情况补合作/委托/任务合同、修改他人软件授权、继承或转让证明等。官方表格及签章页使用平台当时生成版本，不复制旧签字、证件或自制官方样式。

中国版权保护中心本次自动访问返回403，未登录当前账号表单。上传文件类型、大小、字段长度、声明及签章内容尚不能认定为“2026年最新已核实”。Agent需在后续实际申请时检查当前官网/账户页面，保存来源、截图或文本及日期；不要复述代理文章里的固定字数或旧纸质流程。

已有AI辅助事实应如实保留。不得推断人工审阅、改写或排版后即可承诺“从未使用AI”；若平台声明与事实不相容，应记录并向登记机构核实。技术预检通过仅说明准备包的技术检查结果，不等于正式提交条件满足或保证获证。
