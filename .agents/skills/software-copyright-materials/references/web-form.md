# 网页申请字段

用户确认这些内容填写在网页申请表，不只是说明书中的介绍。2026年10月1日截图显示：开发/运行硬件、开发操作系统、开发工具、运行平台、支持软件、开发目的、行业各最多50字；主要功能500至1300字；技术特点文本最多100字。具体值见web-form-schema.json，以当前截图或页面计数器替换失效限制。

先读取已有申请信息填写清单.md，更新同一文件。提供与界面同顺序、可直接粘贴的短文本；主要功能采用完整功能描述，不能把前述50字用途当作主要功能。用scripts/check_web_form.py校验所有短字段、主要功能上下限和技术特点100字；留意换行与英文也被界面计数。

- 软件全称与版本分开，名称须和两类PDF一致。简称没有实际使用值时留空，不写“无”。
- 原始/继受取得及全部/部分权利按真实来源和范围确认，不因模板署名推定。开发完成日期采用用户给出的真实日期，不使用归档日期。
- 硬件环境使用实际配置，不把测试配置写成未经验证的最低配置；开发系统与运行系统区分。生成运行JS不意味着原创源码以JavaScript编写，语言勾选来自实际源文件；缺少TypeScript可用其他补充，不误选Java。辅助启停脚本可补充PowerShell。
- 源程序量只填真实统计数字，不填“行”，不包含依赖和生成代码。明确统计范围并与鉴别材料映射一致。
- 行业和技术类别按产品用途。当前天平项目为教育教学与实验训练，勾选教育软件；本次AI辅助制作不等于软件内置AI功能，未实现不勾人工智能、VR、物联网、云计算等类别。
- 主要功能描述实际操作、输入、反馈、评分、记录、报告、导出及边界；技术特点描述实际架构、状态验证、数值处理和保存方式，避开宣传性评价与虚构性能。

截图中的限字规则保存在schema中供追溯；未登录用户账号验证其他页面，不能声称已核验整个平台或自动提交。
