# 合作开发协议模板使用

默认模板：../assets/agreement-template/合作开发协议模板.docx。模板来自用户选定的开发协议DOCX，保留十二章节原条款、页眉页脚、字体、段落和签署表格，已清除原项目人员、名称、日期及份额。它是协议的内容与格式依据；不要另起TeX协议、重新设计版式或任意增删条款。

直接复制DOCX并就地修改软件名称、版本、实际功能描述、主体、日期、经办人、分工、份额和份数；核对正文、页眉、签署栏和元数据。版本沿用用户指定值，界面优化或文档修订不自动升级版本。用户未提供的项目事实留待填写，要求占位时用红色XXX，不继承样例事实。

保留按份共有、财产权许可、保密、违约、争议解决等既有条款内容。具体共有方式、份额及签署是否成立仍按本次项目事实填写；不要把模板条款当作各方已签署的事实。用户要求改变条款时按其要求调整。合作人数变化时，相应修改合作方名单、份额列项、分工、份数和签署栏，可复制或删减原组件，保持原有格式。三方可保留两列表格并留空第四格。

章节标题与后续正文保持同页；保留页码域并刷新。以Word或可用DOCX渲染工具导出PDF，逐页检查标题孤行、表格跨页、姓名和签署空间。交付DOCX及配套PDF，说明书和源程序仍使用原有TeX流程；打包脚本不得用旧TeX协议覆盖DOCX导出的PDF。

模板和最终协议分开保存。对外同步模板时保留匿名占位，检查正文、表格、页眉页脚、批注、修订和文档元数据，排除原项目个人信息。
